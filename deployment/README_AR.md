# إعداد خدمة الوجه على خادم العميل

هذه الخطوات لمُثبّت Linux ضمن الموديول. نفّذها مسؤول الخادم مرة واحدة بعد تثبيت إضافة Face Attendance في Odoo.

## المتطلبات المدعومة

- Ubuntu 22.04 أو 24.04 مع systemd.
- خادم Odoo يعمل على نفس الخادم مباشرة، وليس داخل Odoo.sh أو Docker.
- صلاحية root أثناء التثبيت، واتصال إنترنت لتنزيل حزم Python من مستودعاتها.

## التثبيت والربط

1. افتح Terminal على خادم Odoo ونفّذ: `sudo bash /path/to/ff_face_attendance/deployment/install-local-face-service.sh`.
2. انتظر حتى تظهر رسالة أن الخدمة أصبحت Ready، ثم انسخ رمز الربط الذي يظهر مرة واحدة.
3. في Odoo افتح **الحضور بالوجه → ربط خدمة الوجه** وأدخل الرمز. لا تدخل أي مفاتيح سرية يدويًا.
4. بعد تأكيد الربط، يظل التحقق بالوجه متوقفًا حتى يفعّل مسؤول الموارد البشرية سياسة الشركة.

المثبّت ينشئ مستخدم Linux غير جذري، ويشغل الخدمة محليًا على `127.0.0.1`، ويولد المفاتيح وشهادة TLS ذاتيًا، ويخزنها بصلاحيات محدودة. نموذج YuNet المرفق يُتحقق من بصمته قبل التثبيت. لا تُرسل صور الوجه أو ملف المعرض خارج خادم العميل.

المثبّت لا يغيّر قاعدة بيانات أودو ولا يستبدل مفاتيح تثبيت قائم. تحديث الخدمة أو تدوير مفتاح التشفير له إجراء منفصل لتجنب فقدان صور التسجيل المشفرة.

## خارج نطاق المثبّت

Odoo Online وOdoo.sh وDocker وتوزيعات Linux الأخرى تحتاج نشرًا منفصلًا للخدمة. استخدم `../FACE_SERVICE_SETUP.md` كدليل إعداد يدوي. هذه التجربة لا توفر كشف تزوير قويًا؛ راجع مراجعة الخصوصية واختبر الكاميرا قبل تشغيلها للموظفين.
